1. ONE LINK, FULL PIPELINE  (download -> watermark -> transcript/SRT)
--------------------------------------------------------------------------------
dllink https://www.instagram.com/p/SHORTCODE/
    - wraps bin/call_router.py; mounts the USB drive if needed
    - log: ~/Desktop/claude/<today>/dllink_<time>.log
    - no URL = uses the link saved in ~/Downloads/link.md
dllink --list FILE                          every link in FILE, one at a time   (added 2026-10-04)
    - 60-180 s between links (DLLINK_GAP="MIN MAX" to change)
    - logs: ~/Desktop/claude/<today>/dllink_list_<time>/ (<shortcode>.log + _progress.log)
    - finished links go in FILE.done and are skipped next time: Ctrl-C safe, re-run carries on
    - checks the USB drive is writable first and before every link; stops if it isn't
python -m lib.drive_check                   is the USB drive for outputs/ really writable? (test write)
python bin/call_router.py "URL"            same thing, no wrapper (exits 1 if anything failed)
python bin/call_router.py "URL" --dry-run  show what it would do

    Re-running is safe: finished steps are skipped and only missing ones run.
    Carousels: every video in the post gets processed (since 2026-10-03).
    Photo posts: downloaded at full size, no watermark/transcript (by design).
    DON'T use bin/call_download.py for a real run: download only, it skips the rest.

3. SCRAPE AN ACCOUNT'S WHOLE POST HISTORY  (metadata only)
--------------------------------------------------------------------------------
U=ldsabuseonx; python -m igp.profile_history $U conf/instagram.cookies.haddamgoel.txt \
    outputs/ig_timelines/${U}_$(date +%F) 150 2>&1 | tee ~/Desktop/claude/$(date +%F)/logs/scrape_$U.log
    - 150 = max scroll rounds (raise it for big accounts)
    - output: <account>_timeline.jsonl (shortcode, date, caption, slides, collaborators)
    - scrolls fast (1.5s), so one account at a time
    - list of accounts to do: ~/Desktop/claude/2026-10-03/collabs_to_scrape.txt

WORD SORT of a scrape (what an account talks about, who it tags, when it posted)
python bin/ig_word_sort.py outputs/ig_timelines/ldsabuseonx_2026-10-04
python bin/ig_word_sort.py outputs/ig_timelines/*_2026-10-04        (one report per account)
    - writes ~/Desktop/claude/<today>/analysis/<account>_word_sort.txt
    - posts per month, collaborators, locations, @mentions, #hashtags, words, word pairs
    - works on scrapes (above) and forensic captures (bin/ig_scrape_account.py)
    - --top 60 for longer lists, --print to also show it in the terminal

WORD HISTOGRAM of transcripts (what the videos say, top words as a bar chart)
python bin/srt_word_histogram.py outputs/2026-10-05/instagram__*/*.srt -o ~/Desktop/claude/<today>/analysis/NAME --title "..."
    - several SRTs are counted together; filler words dropped (--all-words keeps them, --pt drops Portuguese ones too)
    - writes NAME_word_counts.txt (every word) + NAME_word_histogram.png (top 30; -n changes it)
    - chart has a key; a dated copy goes in analysis/history/ each run
    - default output (no -o): ~/Desktop/claude/<today>/analysis/<first SRT name>

TRANSCRIPT SAMPLE (cursory look at N random transcripts from a dllink --list run)
python bin/srt_sample_report.py --done LIST.urls.txt.done --tsv LIST.tsv -n 3          (then --more for 3 new ones)
    - per post: date, where found, why it ties, credited, uploader, length, top words
    - every caption line matching friend / Backfire / SRA, with its time (--term to change)
    - writes ~/Desktop/claude/<today>/analysis/srt_sample/report_<time>.md

STICKER (WATCH BUTTFIRE on any card going out)

COLLABNET — walk a collaborator network (its own pipeline, not dllink)
collabnet ~/Desktop/claude/<today>/QUEUE.txt                 accounts in the file, one after the next
collabnet QUEUE.txt --snowball --max-accounts 10             also queue each account's new collaborators
collabnet QUEUE.txt --dry-run                                say what it would scrape, scrape nothing
    - queue file: one account per line, anything after # is a comment
    - per account: scrape (skipped if we already have it) -> word sort; ONE graph at the very end of the run
    - waits 3-6 min between accounts (--gap MIN MAX), 3-6 s between scrolls (--pause)
    - output: ~/Desktop/claude/<today>/collabnet_<queue name>/
          run_<time>.log  status.tsv  word_sorts/  graph/collab_graph.html (.png, edges.tsv, nodes.tsv)
    - Ctrl-C is safe; run the same command again to carry on
    - accounts that hit the scroll cap are logged CAPPED and listed in capped_<queue>.txt
      (next to the queue file) with the re-scrape command at its top
python bin/ig_tagged_posts.py timballard89 --name 'tim\s*ballard' --queue QUEUE.txt
    - every post in those accounts' scrapes that ties to timballard89 (collaborator, @, or named)
    - writes ~/Desktop/claude/<today>/analysis/timballard89_tagged_posts.tsv + .urls.txt
    - then: dllink --list ~/Desktop/claude/<today>/analysis/timballard89_tagged_posts.urls.txt
python bin/ig_collab_graph.py                                graph of ALL scrapes we have
python bin/ig_collab_graph.py --center hiddenwarmovie --depth 2
EVIDENCE-GRADE GRAPH of a group (added 2026-10-04)
python bin/ig_group_members.py --seeds GROUP.txt --out DIR                 who's in the group: seeds + accounts tied to 2+ seeds
python bin/ig_collab_graph.py --members DIR/members.txt --evidence --names --label-all --out DIR/graph
    - GROUP.txt: one account per line, '# where our own work placed it' after it
    - --evidence writes inputs.tsv (sha256 of every scrape used), edge_posts.tsv (every post behind every
      line), members.tsv and manifest.json (code version, command, hash of every output)
    - --names labels dots "Display Name / @handle" from downloaded-post metadata (+ a names TSV if given)
    - --inputs FILE,FILE uses only those scrapes instead of all of them

WHEN SOMETHING LOOKS WRONG
--------------------------------------------------------------------------------
- 0 posts / cover-image-only / "No video formats": check the cookies first (7)
- photos missing on a carousel: re-run dllink on it, finished steps are skipped
- a step didn't run: look at the metadata/<vendor>__<id>.json "default_tasks" block:
    true = still to do, a path = done, false = turned off
